# 🍽️ Food Preorder Management System

Personal project by [Salman Zulkarnain](linkedin.com/in/salmanzulkarnain)

A full-stack web application for managing food preorder businesses, combining a customer-facing storefront with an admin dashboard for product, order, and payment management.

🔗 **Live Demo:** preorder-app-pi.vercel.app

## 🎯 Project Goals

This project is designed to help a food business manage:
- product catalog
- customer orders
- cart and checkout flow
- online payment integration
- transaction monitoring
- basic admin operations

It is built as a modern Next.js app with a PostgreSQL database and Prisma ORM.

## ✨ Main Features

### Customer-side
- Browse available food products
- Add products to cart
- Update/remove cart items
- Checkout and create orders
- Track transaction status via invoice page

### Admin-side
- Login to admin panel
- View dashboard summary
- Manage products (create, update, delete)
- View recent transactions and payment status
- Export product and transaction data
- Monitor payment activity

### Additional
- Midtrans payment integration
- Product image upload
- WhatsApp subscriber form
- Responsive UI for desktop and mobile

## 📁 Project Structure

- app/ — pages, layouts, and API routes
- components/ — reusable UI components
- lib/ — helper utilities, auth context, Prisma client
- prisma/ — database schema and migrations
- public/ — static assets and uploaded images
- types/ — TypeScript type definitions
